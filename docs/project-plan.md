# 会话式数据分析代理 - 项目计划

## 产品愿景

创建一个会话式数据分析代理POC，让用户能够通过自然语言对话获取数据分析结果，并以交互式图表的形式直观地展示这些结果。

## 开发方法

采用Scrum敏捷开发方法，分为3个冲刺，每个冲刺为1周。

## 产品待办列表

### 高优先级
- 项目基础设置与聊天界面
- 数据分析意图识别
- 模拟数据服务

### 中优先级
- 图表消息组件
- 图表交互功能
- UI/UX优化

### 低优先级
- 高级数据分析功能
- 数据导出功能

## 冲刺计划

### 冲刺1：项目基础与聊天界面（1周）

**目标**：从GitHub下载ai-chatbot项目，设置基础环境，确保聊天界面正常工作。

**任务**：
1. ✅ 从GitHub克隆ai-chatbot项目
2. ✅ 配置开发环境
3. ✅ 隔离不需要的功能（数据库、身份验证、模型连接）
4. ✅ 确保聊天界面正常工作
5. ✅ 创建模拟AI响应服务

**完成标准**：
- 项目可以成功启动和运行
- 聊天界面功能正常
- 不依赖于外部服务

### 冲刺2：数据分析与可视化基础（1周）

**目标**：实现聊天形式的数据分析体验，集成natural-language-postgres的UI/UX模式。

**阶段1：数据分析组件库** ✅ **已完成**
1. ✅ 创建数据分析组件目录结构
2. ✅ 复制并适配核心组件
   - 建议查询组件 (DataAnalysisSuggestedQueries)
   - 动态图表组件 (DynamicChart) - 支持bar/line/area/pie
   - SQL查询显示组件 (DataAnalysisQueryViewer)
   - 数据结果组件 (DataAnalysisResults) - Table/Chart切换
3. ✅ 添加必要的UI组件 (chart, table, tabs)
4. ✅ 安装依赖 (recharts, @radix-ui/react-tabs)
5. ✅ 验证组件正常工作

**阶段2：模拟数据服务** 🚧 **进行中**
1. 创建独角兽公司数据集
2. 实现意图识别服务
3. 创建SQL生成服务
4. 集成到聊天API

**阶段3：聊天界面集成** 📋 **待开始**
1. 扩展消息类型支持数据分析
2. 在聊天界面显示建议查询
3. 在消息流中显示数据结果
4. 实现完整的用户交互流程

**完成标准**：
- 用户可以在聊天界面看到建议查询按钮
- 点击建议或输入查询后，AI返回SQL查询和数据结果
- 数据结果支持Table/Chart切换显示

### 冲刺3：高级图表功能与优化（1周）

**目标**：实现高级图表交互功能，优化用户体验，完成最终POC。

**任务**：
1. 实现图表类型切换功能
   - 创建图表类型选择器组件
   - 实现图表类型状态管理
2. 实现图表详细视图模态窗口
   - 创建模态窗口组件
   - 实现图表放大显示
3. 实现表格视图
   - 创建表格组件
   - 实现表格/图表切换功能
4. 优化UI/UX
   - 添加动画和过渡效果
   - 优化响应式设计
   - 确保暗/亮模式支持

**完成标准**：
- 用户可以切换图表类型
- 可以查看详细图表视图
- UI响应流畅且美观

## 技术架构

### 前端
- **框架**：Next.js 14
- **样式**：Tailwind CSS + Shadcn UI
- **图表库**：Recharts
- **状态管理**：React Context/Hooks

### 数据处理
- **模拟数据**：JSON格式的预定义数据集
- **数据转换**：客户端数据处理和转换

## 风险和缓解策略

1. **项目依赖兼容性问题**
   - **风险**：ai-chatbot项目可能有特定的依赖版本要求
   - **缓解**：使用Node.js v20.12.1，确保依赖版本兼容

2. **功能隔离挑战**
   - **风险**：移除某些功能可能影响其他功能
   - **缓解**：逐步隔离功能，每次修改后测试

3. **UI一致性**
   - **风险**：集成数据可视化可能破坏原有UI
   - **缓解**：遵循ai-chatbot的设计系统，确保一致性

## 定义完成

对于每个任务，满足以下条件才能视为完成：
1. 代码已实现并通过代码审查
2. 功能符合验收标准
3. 文档已更新
