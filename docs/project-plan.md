## 🏗️ **最终技术架构**

### 前端技术栈
- **框架**：Next.js 15 + TypeScript
- **样式**：Tailwind CSS + Shadcn UI + Framer Motion
- **图表库**：Recharts
- **状态管理**：React Context/Hooks
- **AI集成**：模拟 AI 响应系统

### 数据处理
- **模拟数据**：独角兽公司数据集（JSON格式）
- **意图识别**：基于正则表达式的模式匹配
- **SQL生成**：模拟SQL查询生成
- **数据持久化**：文件系统存储（开发环境）

### 架构模式
- **Artifact 系统**：统一的内容展示面板
- **工具调用**：AI SDK 工具调用模式
- **流式响应**：实时数据流处理
